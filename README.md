# SEA LEGS CUP

SEA LEGS CUPの大会サイトです。Vue 3 + Viteで構成しています。

## セットアップ

```bash
npm install
```

## 開発サーバー

```bash
npm run dev
```

## 本番ビルド

```bash
npm run build
```

`canonical` や OGP の URL を本番ドメインに合わせる場合は、ビルド前に `VITE_SITE_URL` を設定します。

```bash
VITE_SITE_URL=https://example.com/ npm run build
```
